# Atlas Kalimdor & Eastern Kingdoms

An instance map module for the World of Warcraft Atlas addon, covering
Kalimdor and the Eastern Kingdoms.

Requires the Atlas core addon.

## Naming and Compatibility

This module was previously named Atlas Classic WoW.

The current name describes its map coverage, not a specific WoW client.
Choose a release compatible with your game client.

The installed addon folder and package name remain `Atlas_ClassicWoW`
for continuity with existing installations and integrations.
